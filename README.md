# SEED Labs: Packet Sniffing and Spoofing
This repository holds the documentation I created when completing the exercises associated with the SEED Lab: Packet Sniffing and Spoofing.

These lab exercises were created by Wenliang Du for the SEED Security Labs project. The instructions can be found [here](https://seedsecuritylabs.org/Labs_20.04/Networking/Sniffing_Spoofing/).

I completed these exercises in April of 2026 as an assignment for my CS438 course at The University of Alabama. A formal lab report in IEEE format can be found here, titled **"LAB REPORT.pdf"**. It provides the details of how I completed each exercise and includes pictures to demonstrate each task.

These exercises were performed using VirtualBox on a Windows machine with a pre-built virtual machine (VM) provided by the lab instructions. The VM ran Ubuntu Linux v20.04. Within the VM, Docker and Wireshark were among the apps used.

Further details can be found in the introduction and setup sections of the formal lab report.
